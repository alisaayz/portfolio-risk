# Checkpoint 3 evaluation protocol

## Risk and screening

Use the accepted aligned daily return panel and the exact as-of close. Historical downside deviation is the square root of 252 times the mean squared return shortfall below zero across **all** observations in the selected window. Report the worst observed one-session return and its end date across the common replay. Keep direct instrument categories separate from underlying overlap.

For each admissible replacement, score the same candidate and same swap on 63, 126, and 252 complete matching sessions using both sample covariance and Ledoit–Wolf shrinkage toward a scaled identity. Use the same holdings-plus-candidate columns for the current and candidate estimate within each cell. A manual target applies to every cell. If using the current portfolio as ceiling, recompute that ceiling in each cell. All six pass means stable within target. All six fail means above target. Mixed decisions mean sensitive to window or estimator. Missing evidence means incomplete. Exposure and eligibility exclusions override any volatility label. Rank by estimated volatility in each cell among the common complete, eligible candidates. The paired interval uses 400 deterministic circular block resamples of length 10 on the selected-window historical return pair, from 126 matched sessions onward. It describes sampling variation of the historical sample-volatility difference. It is a nominal interval without a multiple-comparisons correction. [Estimator reference](https://scikit-learn.org/stable/modules/generated/sklearn.covariance.LedoitWolf.html)

## Transaction-cost replay

Replay daily and at completed calendar-month closes, using adjusted-return dollar exposures and fractional units. Hold exposures between trades. For each rebalance solve for post-cost wealth such that it plus costs on both buy and sell dollars equals pre-trade wealth. Compare zero cost, 5 basis points per traded dollar, and a 25 basis point wider-spread scenario. Treat initial allocation as already held and exclude liquidation, tax, market impact, and fixed fees. The assumed charges are scenario parameters.

## Allocation policy comparison

Fix four examples before evaluation. Use AAPL/SPY/BND at 30/50/20 and 10/40/50, QQQ/IWM/IEF/GLD at 35/25/25/15, and MSFT/JPM/EFA/LQD/HYG at 25/15/25/25/10. Use the first session of each of 2023–2025 as a grid anchor, step by 20 sessions, and drop windows crossing year-end. Fit 252-session sample covariance through each origin. The move budget is 10%. Lock AAPL in the first example and cap LQD at 30% in the fourth. Use the same bounds and budget for keep-current, a single move from highest to lowest standalone volatility with sell/buy capacity, and constrained minimum variance. Revert the simple move to current when it fails to reduce estimated volatility. Enter the selected mix at the origin under the same cost assumptions and let weights drift for 20 sessions. Report feasibility, annualized gross realized downside deviation, terminal net return at both cost assumptions, and planned turnover. Average portfolios equally within matched origins.

The simple rule is the default unless the optimizer reduces mean annualized downside deviation by at least 0.25 percentage points, reduces mean downside on more than half of the shared dates, and reduces mean net terminal return at 5 basis points by no more than 0.10 percentage points. Retain the optimizer as an explicit comparison. Report paired uncertainty on shared dates with 2,000 circular block resamples of three adjacent origins within each year. Treat this as development evidence from a survivor sample.
