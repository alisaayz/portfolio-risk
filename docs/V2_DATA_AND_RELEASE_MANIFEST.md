# Version 2 data and release manifest

Reviewed November 5, 2026. The preview is intended for local evaluation. Its standalone demo generates fictional prices. The archived research workflow uses separately retained market inputs.

| Material | Where it lives | Preview treatment |
| --- | --- | --- |
| Project software and synthetic test fixtures | `app/`, `scripts/`, `sql/`, `tests/`, and `config/` | Public source. The repository has no project-level software license. Dependency licenses are separate. [GitHub licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) |
| Standalone demo prices | Generated by `scripts/synthetic_app_demo.py` in a temporary DuckDB | Fictional tickers and returns. The demo runs without a market provider account or a copy of the research archive. |
| Provider price and action captures, comparison pages, and normalized tables | Local `data/audit/`, `data/validation/`, `data/normalized/`, `data/warehouse/`, and `data/application_market/` | Retained separately. Automated Yahoo access and redistribution require checking the applicable rights. Provider downloads are disabled by default in the Version 2 server. [Yahoo terms](https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html) · [yfinance guidance](https://ranaroussi.github.io/yfinance/) |
| FRED and quarantined Yahoo benchmark captures | Local `data/validation/` and warehouse context tables | Used as source audit context. FRED series can carry third-party restrictions. These benchmark rows are outside the portfolio return and model inputs. [FRED terms](https://fred.stlouisfed.org/legal/terms/) |
| Nasdaq Trader symbol directory | Local `data/symbol_directory/` | Saved for discovery. The project has no documented redistribution permission for this specific file. Its footer records file creation time. [Nasdaq Trader directory definitions](https://www.nasdaqtrader.com/trader.aspx?id=symboldirdefs) |
| Selected check metadata and fund facts | `config/archived_price_checks.json`, `config/fund_evidence.json`, and reports | Public counts, dates, and links to original sources. Spot checks cover five closing dates per selected instrument. Upstream vendor independence remains unverified. Fund documents are linked and aggregate observations are labeled with their dates. |
| Model artifacts and prospective predictions | Local `data/modeling/`, `data/experiments/`, and `private/prospective/` | Training artifacts, serialized models, and raw prediction rows stay local. Public reports summarize completed research. |
| Personal entries and study observations | Browser memory, optional browser weight draft, and opt-in local study store | Outside the public demo artifacts and version control. The server binds to localhost. |

A wider screening universe requires accepted price and identity evidence plus dated exposure records. The directory describes a current selection of instruments. Research with delisted securities and point-in-time membership requires a separate licensed or otherwise authorized source. No new provider access or redistribution approval was established in this checkpoint.

The source audit preserves three quarantined Yahoo index discrepancies. The displayed spot checks do not establish continuous independent coverage, and fee and composition coverage is limited. The synthetic demo stays separate from this evidence. [Reproduction commands](REPRODUCE.md)
